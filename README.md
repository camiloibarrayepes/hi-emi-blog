# Hi Emi Blog

Proyecto estático listo para GitHub Pages.

## Archivos

- `index.html`: listado de consejos.
- `article.html?id=1`: detalle dinámico.
- `data/articles.json`: contenido editable.
- `css/style.css`: estilos.
- `js/script.js`: listado y filtros.
- `js/article.js`: detalle, lectura y compartir.

## Publicación

Sube todo el contenido manteniendo las carpetas. En GitHub Pages selecciona:

- Branch: `main`
- Folder: `/ (root)`

La URL del detalle será parecida a:

`https://tuusuario.github.io/hi-emi-blog/article.html?id=1`
