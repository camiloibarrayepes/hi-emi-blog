# Hi Emi Blog

Proyecto estático listo para GitHub Pages.

Ahora también incluye páginas públicas para App Store:

- `app.html`: página de marketing de `Hi Emi`
- `support.html`: página de soporte de `Hi Emi`

## Archivos

- `index.html`: listado de consejos.
- `article.html?id=1`: detalle dinámico.
- `app.html`: landing pública para marketing.
- `support.html`: soporte oficial.
- `data/articles.json`: contenido editable.
- `css/style.css`: estilos.
- `css/app-page.css`: estilos de marketing y soporte.
- `js/script.js`: listado y filtros.
- `js/article.js`: detalle, lectura y compartir.
- `js/app-page.js`: página React compartida para marketing y soporte.

## Publicación

Sube todo el contenido manteniendo las carpetas. En GitHub Pages selecciona:

- Branch: `main`
- Folder: `/ (root)`

La URL del detalle será parecida a:

`https://tuusuario.github.io/hi-emi-blog/article.html?id=1`

Si publicas este repo en GitHub Pages, puedes usar por ejemplo:

- Marketing URL: `https://tuusuario.github.io/hi-emi-blog/app.html`
- Support URL: `https://tuusuario.github.io/hi-emi-blog/support.html`
